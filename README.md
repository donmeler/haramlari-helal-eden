# haramlari-helal-eden

Görselin sonundaki satırlara bakınız — 

> "Haramları helal eden Efendimize şükürler olsun."


https://www.youtube.com/watch?v=tcnutUBnWEo

Yalçın Küçük, Bülbülderesi Mezarlığı’nda sadece Sabetaycıların yattığını söyler — _İsimlerin İbranileştirilmesi_ kitabında.

Özellikle “Yok olmaz, bu kadar mı Sabetaycı, beraber yiyip içtiğimiz, yanlışı vardır.” diyenlerin izlemesini diliyoruz. 

Tekrar söylüyorum: Kimsenin dini inancıyla bir derdimiz yok. Dini inancını ve/ya kimliğini saklayanla her türlü derdimiz var.

Bu sayfalar, sadece yarası olanların gocunacağı sayfalardır.
